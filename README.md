# 香港硕士与PhD申请公开资料库

面向内地申请者的香港硕士及PhD专业、申请材料、真实文书索引与作品参考资料站。首页介绍采用粤语繁体，主要功能与申请资料使用简体中文。

当前快照收录 163 个母项目、37 个方向或路径、40 位公开研究人员及 43 条公开案例索引。另有独立PhD分类，首批 18 条四校招生学科/单位档案，不混入硕士计数。硕士录取文书分类有 5 条公开原文及结果说明，作者自述不等于本库独立核验。母项目与内部方向分别计数；收录数量不代表已穷尽全港项目，逐条核验层级与来源学年在网站内展示。

## 访问与功能

- 专业搜索、组合筛选、卡片与表格、详情与官方来源。
- 课程介绍、申请步骤、原创中英文教学选段，按记录分批完善。
- 原创 PS、CV、推荐信及作品说明模板，支持 PDF/TXT 下载。
- 奖学金与资助独立分类：13校35条首批记录，政府与校方、硕士与PhD、非本地资格和年度金额分开；支持下载单项流程及文件清单。
- 当前筛选结果可导出 CSV/JSON，案例可在当前浏览器收藏。

网站为完整单文件前端应用，所需数据、原创 IP 及7类原创 PDF 已内置于 index.html。原创模板共 28 份（硕士18、博士10），分别下载。Tailwind、图标和部分案例预览通过公开网络来源加载。

## GitHub Pages

本目录仅包含 index.html、.nojekyll 与本说明。使用公开仓库的 main 分支根目录作为 GitHub Pages 发布源即可运行，无需服务端构建。更新时替换 index.html 并提交，公开站点以最近一次成功发布为准。

## 投稿与资料更新

当前投稿仅保存在访问者自己的浏览器，不会上传到维护者或云端；可导出后自行交给维护者。网站不收取在线申请材料，也没有集中收件后台。

资料由维护者定时整理，采集完成不等于公开版本已更新。每条资料保留核验日期、来源学年及官方链接；尚未确认的费用、材料或课程规格明确标为未知。申请时请核对校方当期要求。

## 来源与使用

本站为独立整理服务，非高校官方网站。官方事实、编辑建议和原创虚构教学范例分别标注；原创教学范例不是真实成功录取文书；真实申请案例另行分类，只提供公开来源索引、证据说明和原创分析，不构成录取保证。
